# Ismail Booking Pro

Custom WordPress plugin to manage bookings with admin approval, edit, delete, and filtering functionality.

## Features

- Admin booking table with filter by status (Pending, Approved, Rejected)
- Edit and delete bookings from admin dashboard
- Status badges with colors
- Nonce security for delete and update
- Fully sanitized and escaped
- Works in WordPress admin panel

## Installation

1. Upload the `ismail-booking-pro` folder to `/wp-content/plugins/`.
2. Activate the plugin from WordPress admin.
3. Go to **Bookings** menu in the admin dashboard to manage bookings.

## Usage

- Filter bookings by status using the dropdown.
- Edit or delete bookings securely.
- Status badges display booking status clearly.
